# Algorithm

## 线段树

线段树是一棵用于高效存储区间信息的二叉树，支持区间查询和区间更新。每个节点代表一个区间，叶子节点代表单个元素

```plain
数组元素长度 n = 6 时，线段树结构如下：
             [0,5]
            /     \
       [0,2]       [3,5]
       /   \       /   \
   [0,1]  [2,2] [3,4]  [5,5]
   /   \          /   \
[0,0] [1,1]    [3,3] [4,4]
```

- 线段树使用了递归和分治的思想，将大区间不断划分为小区间，直到划分到单个元素
- 使用数组存储线段树时，可以按补齐后的满二叉树估算空间。满二叉树节点数量为 `2 ** height - 1`，叶子节点数量满足 `2 ** (height - 1) >= n`；空间大小可近似为 `2 * 2 ** (height - 1)`，即 `2 << (n - 1).bit_length()`，工程上常用 `4 * n`
  > 使用 `1 << (n - 1).bit_length()` 来获取大于等于 `n` 的最小的 2 的幂次方
- 下标从 1 开始，当前节点下标为 `index`，左子树下标为 `index * 2`，右子树下标为 `index * 2 + 1`
- 区间一般使用闭区间，当前区间为`[left, right]`，左子区间为 `[left, mid]`，右子区间为 `[mid + 1, right]`
- 懒更新在当前节点完整覆盖目标区间时，先更新该节点并记录懒标记；只有后续查询或更新需要访问子节点时，才把标记向下传递

## 库函数

### 二分查找

python 标准库 `bisect` 模块提供了二分查找的功能，常用函数包括：

- `bisect_left(a, x)`: 返回 `x` 在 `a` 中的左侧插入位置
- `bisect_right(a, x)`: 返回 `x` 在 `a` 中的右侧插入位置
