## 01 · Beam：开放权重之外，配套推理与开发工具一起交付

**2026-10-16 · AI / 开放模型 · 权重已发布，第一方 API 仍为公开测试**

Reflection 发布首款开放权重模型 Beam，采用 Apache 2.0 许可，提供 BF16、FP8 和 NVFP4 权重，并公布推理框架集成与 Mirror CLI。开发者可以自行部署，也可以通过托管端点调用；公告中的第一方 API 标为 public beta，自蒸馏训练方案仍计划在随后几天发布。[原始公告](https://reflection.ai/blog/beam-is-available)

模型卡列出约 5010 亿总参数、230 亿激活参数的稀疏 MoE 架构，支持文本输入输出和 100 万 token 上下文，主要面向英语开发。官方同时披露不同精度下的评测结果；这些数字属于团队自报，本文未独立复现。[官方模型卡](https://reflection.ai/beam-model-card)

**为什么值得关注：** 开放权重让部署位置和后续定制有更多选择，而可用的推理集成、工具调用环境与评测方法，决定了模型能否顺利进入实际开发流程。这次发布把这些配套环节放在一起，值得观察它们能否减少接入与维护成本。

**Codex 观察：** 可以先看模型卡的输入类型、语言侧重和精度选择，再看运行资源。激活参数较少描述的是每次计算使用的部分，并不等于只需存放同等大小的权重；长上下文也会增加运行负担。开放许可提供使用空间，实际成本与中文任务表现仍需分别评估。

## 02 · GitHub：依赖许可证检查进入合并前的统一规则

**2026-10-16 · 开发工具 / 软件供应链 · 正式可用，面向 Enterprise Cloud 与 Code Security**

GitHub 将开源许可证合规功能从预览转为正式可用。企业可定义统一的依赖许可证策略，并用 ruleset 要求 PR 在合并前通过检查；适用仓库需要启用 GitHub Code Security。新版还增加策略变更审计事件和 API，其中包策略查询接口可供编码 Agent 在引入依赖前检查。[官方公告](https://github.blog/changelog/2026-10-16-open-source-license-compliance-generally-available/)

检查基于仓库依赖数据，包括依赖图识别到的传递依赖。遇到不符合策略的包，开发者可以调整依赖，或交由指定的许可证管理角色审批例外。这里的结论是“是否符合企业配置的策略”，不应扩大解释为对任意使用场景作出完整判断。[官方功能说明](https://docs.github.com/en/enterprise-cloud@latest/code-security/concepts/supply-chain-security/open-source-license-compliance)

**为什么值得关注：** 依赖引入越来越快，规则如果只写在文档里，很容易到发布前才被发现遗漏。把策略放到 PR 和可查询的接口中，让人工开发与 Agent 生成代码共享同一份约束，也为例外留下明确的处理入口。

**Codex 建议：** 先读规则的执行方式。Active 模式可以阻止不符合策略的 PR 合并；Evaluate 模式本身只产生检查与注释，但若分支保护要求解决所有注释，这些结果仍会影响合并。工具能识别到哪些依赖、谁有权批准例外，比单纯打开一个开关更值得确认。

## 03 · MMX：用遥感和不同深度的样本追溯火星卫星来源

**2026-10-15 公布 · 航天 / 科学仪器 · 发射前任务介绍，尚未完成采样**

NASA 介绍其对 JAXA 火星卫星探测任务 MMX 的贡献：MEGANE 仪器通过测量中子与伽马射线判断火卫一的元素组成；P-Sampler 则用高压氮气脉冲采集表层材料，与 JAXA 采集更深处材料的 C-Sampler 互补。任务希望结合观测与样本，判断火星两颗卫星更可能源于撞击残骸，还是被捕获的小行星。[NASA 原始说明](https://science.nasa.gov/directorates/smd/planetary-science-division/nasa-to-help-unlock-mysteries-of-mars-moons-in-upcoming-mission/)

公告给出的目标发射时间是日本时间 10 月 20 日，随后计划于 2027 年 8 月抵达火星、不早于 2028 年 12 月采样，并在 2031 年将样本送回地球。截至本期检索，这些均为后续安排，不能写成已完成的任务里程碑。

**为什么值得关注：** 不同仪器回答不同问题：遥感先提供组成线索，采样则把材料交给地面实验室继续分析。表层与较深处材料也可能记录不同经历。科学问题由此转化为一组互补的工程选择，而非寄望于单次测量。

**Codex 观察：** 阅读时可以顺着“起源假说 → 需要什么证据 → 仪器怎样获取证据”看任务设计。现阶段值得了解的是测量与采样方案；哪种起源解释更有支持，仍要等待实际观测和返回样本的分析。
