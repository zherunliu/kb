## 01 · Brotli：修复已发布，还要确认应用使用了哪份运行时

**2026-10-25 .NET 发布；10 月 26 日 Azure 更新说明 · 安全 / 基础设施 · 补丁可用，云端分批部署尚未完成**

Microsoft 在常规月度更新之外发布 .NET 8.0.33、9.0.22、10.0.14，以及仍属候选版本的 .NET 11 RC3，修复随运行时使用的 Brotli 解码器漏洞 CVE-2026-111497 等问题。恶意压缩数据可能导致越界写入、进程内存破坏及相关安全影响。公告说明，请求解压、自动响应解压并非默认开启，.NET Framework 不受这一问题影响。[.NET 原始公告](https://devblogs.microsoft.com/dotnet/dotnet-october-2026-oob-security-updates/)

这也是一个跨组件的更新案例：Node.js 已在 10 月 21 日公告同一漏洞，触发条件是应用通过 `node:zlib` 解压攻击者可控制的 Brotli 数据。[Node.js 安全公告](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases)

Azure App Service 团队在 10 月 26 日明确表示，Windows 内置 .NET 运行时正在分批部署更新，不能据此认定所有实例都已修复。应用自带的运行时和自定义容器不由这次平台更新替换，仍需使用修复版本重新构建和部署。[Azure 部署范围与状态](https://azure.github.io/AppService/2026/10/26/dotnet-brotli-security-update-app-service-windows.html)

**为什么值得关注：** 一个底层解码器可能被多个语言运行时打包。供应商发布补丁、宿主安装新版、应用进程实际使用新版，是需要分别确认的步骤；只更新其中一份组件，可能遗漏应用或镜像内部的副本。

**Codex 建议：** 若使用相关技术栈，优先核对实际运行版本、部署方式和不可信压缩数据的处理入口，再按对应供应商说明更新。这里的风险条件是解码路径可达，不能把“安装了相关运行时”直接写成“服务必然可被远程利用”。

## 02 · 近期补读：Supabase 让 MCP 工具沿用用户的数据权限

**2026-10-22 · AI / 开发工具 · MCP Server 代码块已提供，需自行配置并部署**

Supabase 推出可加入现有应用的 MCP Server 代码块，让用户从兼容的 AI 客户端调用应用功能。它把服务代码复制进项目，使用官方 MCP TypeScript SDK 注册工具，由 Supabase Auth 处理 OAuth 登录与授权。每次工具调用携带用户令牌，辅助库验证后向处理函数提供该用户的 Supabase 客户端。[发布介绍](https://supabase.com/blog/give-your-supabase-app-its-own-mcp-server)

查询因此可以沿用 Postgres 的行级安全策略（RLS），决定当前用户能访问哪些记录。开发者仍需选择暴露的业务动作、定义输入和返回值，并完成 OAuth 与授权页面等配置；这不是自动把整个数据库变成任意查询入口。[代码块与配置文档](https://supabase.com/library/docs/headless/mcp)

**为什么值得关注：** 当同一应用增加网页之外的 Agent 入口，授权逻辑容易出现重复或遗漏。将调用者身份一路带到数据查询，使已有策略有机会继续生效，也让产品可以围绕用户已有账户提供工具能力。

**Codex 观察：** 可以重点看“登录用户 → 工具处理函数 → 数据库客户端”的链路。RLS 能约束相应数据库访问，但调用外部服务、发送通知等业务动作仍需各自检查权限；工具声明为只读，也不能代替服务端实际限制。代码块提供接入起点，最终边界仍由应用实现决定。

## 03 · PACE：从太空追踪叶片颜色的变化

**2026-10-26 案例解读 · 科学探索 / 遥感 · 展示 9 月 29 日至 10 月 11 日观测，并非当天发射的新卫星**

NASA 展示 PACE 卫星的秋季植被观测。其 OCI 高光谱仪利用多个波段观察叶绿素、类胡萝卜素和花青素相关信号，再通过颜色指标的时间变化，追踪不同地区的秋色进程。文中对比两段观测时窗，展示偏红区域随时间向较低纬度扩展。[NASA 案例与观测日期](https://science.nasa.gov/earth/earth-observatory/hunting-red-leaves-with-satellites/)

**为什么值得关注：** 高光谱遥感能把肉眼看到的颜色变化转成可反复比较的指标。连续观测有助于研究植被季节节律；相比一张漂亮的照片，时间序列更能说明变化在何时开始、如何推进。

**Codex 观察：** 图中偏红并不都代表秋叶，作物衰老、收获、干旱或虫害也可能影响色素；云遮挡还会造成缺测。团队正在借助地面照片校验解释，探索后续生态研究用途。可以先看对照图，再读这些限制，避免把颜色指标直接等同于植物健康诊断。
