## 01 · 近期补读：agent-desktop 把桌面界面变成可操作的结构

**2026-10-30 发布 · AI / 开源开发工具 · 1.0.2 版本已发布，Apache 2.0 开源**

Vercel Labs 的 agent-desktop 发布 1.0.2，改进权限引导，增加 npm 启动器性能提示，并补全文档站点。此次是已有项目的版本更新，不是桌面操作能力当天首次出现。[版本记录](https://github.com/vercel-labs/agent-desktop/releases/tag/v1.0.2)

项目通过操作系统的无障碍接口读取应用界面，向 Agent 返回带元素引用的 JSON 快照。Agent 选择一个引用执行点击或输入，再读取快照确认变化；任务规划仍由接入它的 Agent 负责。它提供 macOS、Windows、Linux 的 CLI 和 C 库，核心路径不依赖从截图中猜测按钮坐标。[项目说明与交互示例](https://github.com/vercel-labs/agent-desktop)

**为什么值得关注：** 网页自动化可以读取 DOM，桌面自动化也需要明确的操作对象。把窗口、按钮和输入框表达为结构，有助于让模型围绕元素身份组织动作，并在界面变化后重新确认目标。是否可靠，仍取决于具体应用暴露的信息与平台支持。

**Codex 建议：** 先看“读取 → 操作 → 再读取”的示例与权限要求。macOS 需要无障碍权限；Linux 需要用户图形会话，不能把普通 SSH 会话当成完整桌面环境。检索时 Homebrew 和 Scoop 默认目录收录仍在申请中，npm 包与 GitHub 制品则已有安装入口。源码可用和所有应用均可稳定操作，是不同层面的判断。[安装与平台限制](https://github.com/vercel-labs/agent-desktop/blob/main/docs/install.md)

## 02 · 近期补读：扩展名称可信，仍需核对分发渠道

**2026-10-29 事件；10 月 30 日技术分析 · 安全 / 软件供应链 · 已公开样本分析，不能据此判定每台设备均被入侵**

Microsoft 分析了通过 Cursor 扩展市场分发的篡改版 `anthropic.claude-code`，涉及 2.1.312 和 2.1.313。其公告明确，恶意包没有通过 Microsoft Visual Studio Marketplace 或 npm 的 `@anthropic-ai/claude-code` 分发；当时证据指向 Cursor 市场，不能把所有同名工具概括为受影响。[Microsoft 原始分析与范围说明](https://www.microsoft.com/en-us/security/blog/2026/10/30/inside-malicious-claude-code-branded-cursor-extension-persistent-ssh-backdoor/)

被注入的代码会在扩展加载时运行，尝试写入 SSH 授权密钥、建立反向隧道并配置持久化。远程访问是否成功取决于主机权限和 SSH 配置，但隧道失败也可能留下密钥或启动项；样本具备这些行为，不代表每一步都在每台机器上成功执行。

**为什么值得关注：** 编辑器扩展能执行本地代码。熟悉的名称和正常工作的界面，无法单独证明安装包来源可靠；调查需要把市场、版本与实际制品联系起来。

**Codex 建议：** 若曾从该渠道安装相关版本，优先按原文核查安装记录与终端证据，再处理确认的恶意残留；不能仅用卸载扩展代替调查。凭据轮换应结合暴露证据决定。本文没有检查你的设备，也没有证据判断你受到影响。

## 03 · TSIS-2：为延续太阳能量记录，先通过地面环境考验

**2026-11-02 公告，测试于今年秋季完成 · 科学仪器 / 航天 · 地面测试通过，发射目标为 2027 年初**

NASA 宣布太阳辐照度测量卫星 TSIS-2 完成热真空、振动及质量特性测试。团队用冷热与真空环境检查整星和仪器，用振动测试模拟发射载荷；后续仍需运输、与火箭集成和发射，当前不能写成已经开始在轨观测。[NASA 测试进展](https://science.nasa.gov/blogs/tsis-2/2026/11/02/nasas-mission-to-study-sunlight-completes-vacuum-vibration-testing/)

它的两台仪器分别测量抵达地球大气层顶部的太阳辐射总量，以及能量在紫外、可见光和近红外波段的分布。任务计划延续始于 1978 年的总辐照度记录和始于 2003 年的光谱辐照度记录；公告给出的发射目标是 2027 年初，使用 Rocket Lab Electron 火箭从新西兰发射。

**为什么值得关注：** 研究缓慢变化，需要跨越多代仪器的长期数据。新仪器的价值也在于接续观测，让研究者比较太阳能量输入的细微变化，而不仅是获得一次更清晰的图像。

**Codex 观察：** 适合把这条消息当作科学测量工程的一个切面：仪器原理、环境适应性和长期观测，各有独立的验证环节。通过地面测试说明任务向发射推进；数据能否接续、实际测量质量如何，还要等待在轨校验与后续科学数据。
