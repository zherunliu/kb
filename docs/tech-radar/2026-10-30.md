## 01 · OpenCode：让会话围绕一个目标持续推进

**2026-10-29 · AI / 开源开发工具 · 2.2.1 已发布，图片生成仍需实验性开关**

OpenCode 2.2.1 加入 `/goal <objective>`，在终端界面和桌面端持续执行多轮工作，直到检查流程判定目标完成；同时提供暂停、恢复和清除目标的命令。桌面端还可以从运行活动入口查看后台 shell 的实时输出并停止进程。图片生成与编辑则需要单独启用 `experimental.image_generate`，不能把版本发布等同于所有功能默认开启。[官方版本说明](https://github.com/anomalyco/opencode/releases/tag/v2.2.1)

相关实现说明介绍了会话进入空闲状态时的插件钩子：插件可以补入后续输入，让执行继续；没有新输入时才保持空闲。这使“这一轮回答结束”与“整个目标已经完成”可以分别处理。[已合并的实现说明](https://github.com/anomalyco/opencode/pull/59437)

**为什么值得关注：** 编码任务常常需要编辑、构建、检查结果，再处理后续问题。把目标保留到下一轮，有助于减少反复提醒；把后台进程状态展示出来，也能让用户知道任务究竟在计算、等待，还是需要介入。

**Codex 建议：** 更值得观察的是完成条件是否清楚、暂停是否有效、结果是否有验证证据。持续运行机制本身不能保证任务成功。此次发布还包含直接导入 `@opencode/ai` 时的 provider 删除和入口重命名，公告明确这些改动不改变 CLI、桌面端或 HTTP API；升级影响应按实际使用层级判断。

## 02 · Dependabot：告警开始附带“业务代码能否调用到”的证据

**2026-10-28 · 安全 / 开发平台 · JavaScript 与 TypeScript 公开预览，面向 GitHub Enterprise Cloud**

GitHub 为 Dependabot 告警增加可达性分析。系统结合受影响函数的数据与 CodeQL 静态调用图，寻找仓库代码通向漏洞函数的路径，并给出可达、可能可达、不可达或结果不可用等状态。功能默认关闭，预览要求仓库包含 npm、Yarn 或 pnpm 锁文件，运行于 GitHub 托管 runner。[预览公告与接入条件](https://github.blog/changelog/2026-10-28-prioritize-dependabot-alerts-with-reachability-analysis/)

这一信号用于安排修复顺序，不会自动关闭告警。官方文档强调：找到调用路径不等于攻击者能够利用；没有找到路径也不保证依赖安全。首次扫描后，只要仍有开放告警，系统约每 24 小时重扫，推送代码不会立即触发扫描，预览阶段也不能按需启动。[结果含义与更新频率](https://docs.github.com/en/code-security/concepts/supply-chain-security/about-reachability-analysis-for-dependabot-alerts)

**为什么值得关注：** 依赖树中的漏洞数量可能远超团队一次能处理的范围。调用路径把“某个版本有问题”进一步连接到“应用在哪里使用它”，有助于把严重性、生产环境和实际代码放在一起判断，也方便定位需要检查的入口。

**Codex 观察：** 优先看路径证据与扫描时间。无法排除调用的“可能可达”应与可达告警一起优先处理；扫描失败或超时导致的“结果不可用”，则需要其他证据。代码刚改完时，旧标签尚未更新并不意味着修复无效，反过来也不能用旧的不可达标签替代重新评估。

## 03 · Lucy：抵达特洛伊区域，近距离观测仍在前方

**2026-10-28 公告，页面于 10 月 29 日更新 · 科学探索 / 航天 · 巡航里程碑，首次特洛伊飞掠计划于 2027 年**

NASA 宣布 Lucy 成为首个进入木星特洛伊小行星区域的探测器。这里不是木星附近的一圈卫星，而是与木星共享绕日轨道、分布在其前后方稳定区域的小行星群。工程团队通过无线电信号与背景恒星图像跟踪探测器位置；公告也提醒，太空中并不存在一条清晰的区域边界。[NASA 原始任务更新](https://science.nasa.gov/blogs/lucy/2026/10/28/nasas-lucy-reaches-trojan-asteroid-region-5-years-after-launch/)

Lucy 的首次特洛伊目标 Eurybates 飞掠计划在 2027 年 8 月 11 日进行。当前仍在巡航与准备，团队正安排有限的近距离观测时段。研究人员希望比较这些古老天体，为太阳系行星形成与迁移过程提供约束；这属于后续科学目标，尚不是本次公告已经获得的结论。

**为什么值得关注：** 深空任务把多年航行换成短暂的近距离数据采集窗口。抵达目标所在区域，是轨迹与运行状态上的进展；真正的图像、光谱及其解释，还需要后续观测与分析。

**Codex 建议：** 可以先看原文的轨迹动画，理解“共享木星轨道”与“靠近木星”在空间上的区别，再看首次飞掠时间。此次消息适合跟踪任务阶段，不宜把巡航里程碑写成已经完成目标小行星研究。
