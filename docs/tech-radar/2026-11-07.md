## 01 · Vercel Schedules：定时任务可以随应用运行而改变

**2026-11-04 技术介绍；11 月 5 日更新日志 · 开发工具 / 基础设施 · 全套餐公开 Beta**

Vercel 推出 Schedules，让应用通过 SDK、CLI 或 API 创建一次性或周期任务，无需为每次时间变化重新部署。静态配置可以指向私有函数、HTTP 路径或 Queue topic；运行时创建的动态任务则通过 Queue topic 分发。任务支持启停和手动触发，也能在 Preview 与自定义环境中测试。[公开测试公告](https://vercel.com/changelog/vercel-schedules-is-now-in-public-beta)

官方示例把“明天生成摘要”拆成两个阶段：先保存时间和任务内容，到期后通过队列交给应用；应用读取请求、检查用户当前权限，再启动 Agent。调度服务负责何时送达，具体工作仍由应用代码执行。既有 Cron Jobs 继续可用。[设计说明与示例](https://vercel.com/blog/introducing-vercel-schedules)

**为什么值得关注：** 用户临时设置的提醒、报表和后续处理，往往需要数据库加轮询任务来实现。动态调度把其中的时间管理变成平台能力，让产品可以直接表达“什么时候做”，而不必把每个用户的计划写进部署配置。

**Codex 建议：** 先看动态任务与队列处理函数的连接方式。创建任务时有权限，不代表执行时仍有权限；时区、取消、重复处理和失败后的恢复，也需要结合业务设计。私有函数减少了公开入口，但不能代替应用内部的授权判断。当前为 Beta，适合评估接入方式与运行约束。

## 02 · OpenSSH：修复范围取决于底层库和认证配置

**2026-11-05 · 安全 / 开源基础设施 · Portable OpenSSH 10.6p2 已发布**

OpenSSH 10.6p2 加入一项重要安全规避措施，防止部分 Linux 系统通过 sshd 触发密码认证绕过。发布说明指出，关键环境是使用 musl libc，并在构建与运行时禁用 PAM。维护者认为根因位于 sshd 之外，但可以在 sshd 中阻断利用路径。[项目原始发布说明](https://www.openssh.org/txt/release-10.6p2)

团队还说明，近期收到大量由 AI 发现或辅助发现的问题，其中不少经真实威胁模型分析后并无安全影响；同时，一些有效问题被不同研究者独立发现。项目因此计划更频繁发布修复，减少等待常规版本集中交付的时间。

**为什么值得关注：** 软件安全边界跨越应用、系统库、构建选项与运行配置。一个版本号只能提供初步线索，真正判断风险还要确认实际认证路径。另一方面，漏洞发现速度变化，也在推动开源项目调整补丁发布节奏。

**Codex 建议：** 管理相关主机时，先核对发行版公告、所用 libc、PAM 状态与供应商补丁，再决定更新方案；发行版回移修复时，版本字符串也未必直接变成上游版本号。不要把这次公告概括成“所有 SSH 服务都能绕过认证”。本文未检查你的设备，因此不对具体主机是否受影响作判断。

## 03 · SPLICE：在地球上验证下降过程中的自主选址

**2026-11-04 公告；主要试验于 8 月 27 日进行 · 科学探索 / 自主导航 · 地球飞行验证，软件开放仍按公告列为计划**

NASA 披露，搭载 SPLICE 制导、导航与控制载荷的 Alta-X 无人机，在加利福尼亚州 Rogers Dry Lake 完成模拟月球下降与着陆动作。系统结合传感器数据生成高分辨率数字高程图、评估着陆区域；若判断目标不安全，就引导无人机转向更合适的位置。[NASA 原始试验介绍](https://www.nasa.gov/centers-and-facilities/armstrong/nasa-navigation-experiment-shows-promise-for-planetary-landings/)

此前的集成飞行检查了载荷与无人机之间的通信、数据处理、遥测和指令控制。公告称这次试验提高了技术成熟度，并提到计划通过 NASA 软件目录提供系统，但没有据此确认软件已可下载。这是一则新公布的试验进展，不是 11 月刚完成的月球着陆。

**为什么值得关注：** 自主着陆需要把“感知地形”转化为“选择地点并改变运动轨迹”。无人机提供了一个可以反复验证感知、计算和控制协作的环境，让研究人员在承担实际太空任务之前检查完整流程。

**Codex 观察：** 阅读时可以沿着“传感器 → 地形图 → 安全区域 → 控制指令”理解系统。地球上的飞行结果能支持工程迭代，但月球与火星的重力、光照、尘埃及载体条件不同，仍需后续验证。技术成熟度提升、未来任务集成和成功完成行星着陆，是不同阶段的证据。
