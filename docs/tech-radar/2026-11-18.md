## 01 · GPT-6.2：把完成任务的质量与成本一起比较

**2026-11-17 · AI / 开发工具 · Astra 与 Sol 已发布，可通过 API 使用**

OpenAI 发布 GPT-6.2 Astra 和 GPT-6.2 Sol，分别面向高难度专业任务与日常工作，也接入 ChatGPT Work 和 Codex。公告强调代码、文档、交互界面和工具使用方面的改进，并报告更少的输出 token 消耗；这些是厂商评测与案例，本文没有独立对比。[原始发布公告](https://openai.com/index/introducing-gpt-6-2-astra-sol/)

Astra 的标准 API 输入、输出单价较 GPT-6 Astra 下调 20%，Sol 延续 GPT-6.1 Sol 的单价。开发日志同时说明，两者支持 Responses API 和 Chat Completions，但工具调用要求使用 Responses API；对已有 Agent 集成，这比只替换模型名称多一项需要核对的兼容条件。[11 月 17 日 API 更新记录](https://developers.openai.com/api/docs/changelog)

**为什么值得关注：** 模型升级开始更多围绕完整产物展开：能否遵循模板、修改已有项目、完成交互并验证结果。单次回答质量只是其中一部分，工具调用、重试和人工修订也会影响一次任务最终花费的时间与费用。

**Codex 建议：** 可以先看公告里的同题产物对照，再看价格和适用接口。比较模型时，把验收标准保持一致：结果是否可用、错误是否被发现、需要多少次修订。单价降低是明确变化，但不能直接推导自己的任务总费用一定按同一比例下降。

## 02 · WordPress：候选版开始集中处理真实交互的边缘情况

**2026-11-17 · 开源 / 网站开发 · 7.2 RC1，仅供测试；正式版计划 12 月 8 日发布**

WordPress 7.2 进入首个发布候选版。相较此前介绍的 Beta 1，此次值得关注的是具体修复：Interactivity API 避免旧的导航响应替换较新的内容，区块编辑器修复重复内容、iOS 键盘交互和修订预览问题；后台也改进了跳转链接和插件依赖提示。[原始发布说明](https://wordpress.org/news/2026/11/wordpress-7-2-release-candidate-1/)

官方提供下载、Beta Tester 插件、WP-CLI 和浏览器内 Playground 等测试入口，并要求主题与插件作者继续检查兼容性。RC1 仍在开发中，官方明确不建议用于生产或关键站点；12 月 8 日是计划发布日期，不能视为已交付承诺。

**为什么值得关注：** “旧导航响应覆盖新内容”是很具体的异步时序问题：例如用户连续打开两个页面，较早请求反而较晚返回，如果直接更新界面，就可能把用户带回旧状态。发布说明展示了成熟交互系统如何从功能可用，继续走向快速点击、慢网络和不同输入设备下的可靠性。

**Codex 观察：** 前端开发者可以优先读导航和键盘交互修复，即使不用 WordPress，也能理解问题背后的状态管理。公告确认了修复目标，但没有展开实现细节，不宜据此猜测采用了取消请求还是版本校验；维护站点的人则更值得关注自己的主题、插件和升级流程是否通过候选版测试。

## 03 · Terra：停止采集之后，长期数据仍然有价值

**2026-11-17 公告 · 科学探索 / 遥感 · 退役计划，科学观测预计于 2026-12-01 停止**

NASA 宣布 Terra 卫星将于 12 月 1 日停止采集科学数据。任务最初按六年设计，已运行近 27 年；系统老化和轨道漂移是公告说明的背景。Terra 长期记录陆地利用、野火、烟尘输送、大气组成和冰盖等变化，为多类地球研究与实际应用提供数据。[NASA 原始公告](https://science.nasa.gov/blogs/science-news/2026/11/17/nasas-terra-mission-to-end/)

后续退役过程包括使用剩余燃料降低轨道，再于 2027 年 1 月关闭所有航天器系统。NASA 明确表示，历史数据将继续免费向公众开放。因此，停止产生新观测、关闭航天器和保留数据访问，是三个不同的安排。

**为什么值得关注：** 科学仪器的运行寿命与数据的使用寿命并不相同。跨越几十年的记录可以继续支持回溯分析；对依赖持续观测的数据产品来说，则需要分别处理历史检索和后续数据来源，不能把“旧数据仍可下载”理解为时间序列仍在更新。

**Codex 建议：** 先记住两个计划时间点，再看数据开放承诺。公告没有宣布某一颗卫星能完整接替 Terra 的全部观测能力；若关心具体指标的连续性，还需核对后续仪器、观测时段与数据产品。对普通读者，这是一则理解科学基础设施如何结束运行、保留成果的清晰案例。
