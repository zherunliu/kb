## 01 · Inkling 2 Mini：同一组模型层，可以重复参与计算

**2026-11-20 · AI / 开放权重 · 已发布，模型卡标注 Apache 2.0**

Thinking Machines Lab 发布 Inkling 2 Mini：支持文本与图像输入、文本输出，采用稀疏专家混合与循环架构。模型有 24 层，其中中间 12 层使用共享权重运行三遍，每个 token 因而经历 48 次层计算。模型卡列出总参数 264 亿、激活参数 34 亿；计入重复运行后，每 token 的有效权重激活量为 54 亿。[官方模型卡](https://thinkingmachines.ai/model-card/inkling-2-mini/)

团队同时开放供研究使用的可变循环版本，并提供 Tinker 推理与微调入口。本地运行支持包括至少 32GB 内存的 Apple silicon 设备；发布说明报告混合低精度模型约占 20GB，并展示离线编程案例。这些是厂商提供的条件与演示，本期没有独立性能测试。[原始发布与研究说明](https://thinkingmachines.ai/news/inkling-2-mini/)

**为什么值得关注：** 模型大小、一次推理的计算量和输出长度，是三个相关但不同的维度。复用权重允许在不按相同比例增加参数存储的情况下增加计算，也让“小模型还能怎样提升推理能力”多了一条可研究的路径。它并不意味着循环次数越多就能储存更多知识。

**Codex 建议：** 先看架构示意与运行条件，再看榜单。公告明确表示，多轮对话和复杂约束指令并非它最强的方向；图中部分速度比较还是理论上限。对于本地使用，值得比较的是自己的任务完成率、响应时间和实际内存峰值，不能只用权重文件大小推算整个工作流的资源需求。

## 02 · Onlook：让设计探索直接发生在运行中的代码上

**2026-11-19 社区发布帖 · 开源 / 开发工具 · 重建后的桌面产品已开放；macOS 可下载，Windows、Linux 尚未提供对应发行产物**

Onlook 创始人在 Launch HN 中介绍重建后的产品：桌面应用为真实代码库提供画布，创建 Git worktree、运行项目自己的开发服务器，再把多个页面、尺寸或方案并排展示。用户选择元素并描述修改，接入的 Claude Code 或 Codex 负责编辑代码，结果可以通过普通 Git 差异和 PR 审查。[创始人原始发布帖](https://news.ycombinator.com/item?id=50562320)

项目源码采用 Apache 2.0；当前 README 提供 macOS 下载与源码构建入口，Windows 为后续计划，Linux 尚无发行产物并在收集需求。源码许可不覆盖所有品牌、图标等素材。它还支持独立 HTML 草稿及图片、PDF 等导出，但这些导出物与仓库中的真实应用应分别理解。[项目说明与平台状态](https://github.com/onlook-dev/onlook)

**为什么值得关注：** 设计工作经常需要同时比较多个方向，而代码编辑器通常围绕某个文件或当前任务组织界面。把真实应用放入可排列的画布，可以让页面状态、布局变体和响应式尺寸更容易放在一起讨论；Git 则为探索留下可审查、可舍弃的变更记录。

**Codex 观察：** 可以先看“选中页面元素 → 修改代码 → 对照方案 → 审查差异”的演示。已有开发服务器、路由和依赖能否顺利运行，仍决定具体仓库的适配效果。本地工作区也不等于模型完全离线：接入的 Agent 仍有自己的服务和数据处理方式，桌面编辑器免费与模型服务费用是两回事。

## 03 · 补读 EarthCARE ATLAS：把大气观测变成可以浏览的问题空间

**2026-11-18 · 科学探索 / 数据可视化 · ESA MAAP 宣布入口已可用**

ESA MAAP 开放 EarthCARE ATLAS 入口，提供交互式二维、三维视图，用于探索 EarthCARE 卫星对云、气溶胶和辐射的观测。用户可以浏览不同数据产品与变量；公告将其定位为同时面向初学者和有经验用户的探索环境。[ESA MAAP 原始公告](https://portal.maap.eo.esa.int/earthcare/2026/11/18/earthcare-atlas-now-available-on-esa-maap/)

入口页说明，它把 ESA 与 JAXA 的 EarthCARE 任务观测带到浏览器，既包含近期过境观测，也组织了精选案例。本次新闻是数据访问与展示工具开放，不是卫星当天发射，也不是宣布一项新的气候结论。[ATLAS 数据探索入口](https://portal.maap.eo.esa.int/ini/earthcare/atlas/)

**为什么值得关注：** 原始数据可下载之后，仍需要让读者理解变量、时间和空间之间的关系。二维视图有利于定位，三维视图可以帮助理解垂直结构；精选案例则为第一次接触数据的人提供起点。这类界面把专业数据从“文件集合”进一步变成可探索的材料。

**Codex 建议：** 可以从一个精选案例开始，先确认展示的是哪种变量、哪个时段，再调整视图。漂亮的可视化帮助发现问题，但不能单独给出因果解释；某次过境的观测也不能直接代表长期趋势。本期核实了公告和入口说明，未验证每种变量的覆盖范围或进行定量分析。
