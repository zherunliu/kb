## 01 · Firefox 161：随机视觉变化可以直接写进 CSS

**2026-11-24 · 开源 / 网页开发 · 161.0 已进入正式发布渠道**

Firefox 161 支持 CSS `random()`，可在指定范围内生成随机值，并选择固定步长，用于接受数学函数的样式值。此次正式版还修复了部分会话恢复、输入法和 WebRTC 视频问题；对开发者，新增的样式表达能力更值得单独了解。[Firefox 原始发布说明](https://www.firefox.com/en-US/firefox/161.0/releasenotes/)

MDN 文档展示了长度、角度、时间等类型的用法，以及控制不同元素和属性之间是否共享随机基值的参数。例如 `random(0deg, 360deg)` 可以表达随机角度。文档仍标注为有限可用、尚未达到 Baseline，不能由 Firefox 上线推断所有主流浏览器都支持。[语法、示例与兼容性](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/random)

**为什么值得关注：** 一组装饰元素的大小、角度或动画时长需要变化时，过去常由脚本先生成数值再写入样式。把范围与共享方式放进 CSS，可以让这类视觉规则更集中地维护；也让“每个元素不同”与“多个属性同步变化”有更明确的表达。

**Codex 建议：** 先看随机基值的作用域，再看视觉示例。它并不等于每次悬停都自动重新抽样；如果需要独立变化，应理解缓存键与共享规则。用于实际页面时保留普通样式回退，随机性也不宜影响文字可读性或核心操作的位置。

## 02 · 补读 Lambda：函数能跑半小时，整条调用链仍需配合

**2026-11-19 发布，11 月 24 日周报再介绍 · 基础设施 / AI 工作负载 · 已开放**

AWS 将按需运行的 Lambda Event Functions 超时上限从 15 分钟提高到 30 分钟，覆盖同步、异步和事件源映射调用。Lambda Managed Instances 的同步调用也提高到 30 分钟，其异步和事件源映射调用则保留此前的 90 分钟上限；两种运行方式不能混为一谈。[原始功能公告](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-lambda-30-minute-ondemand-event-functions/)

按需功能在所有商业区域可用，Managed Instances 则以该服务已开放区域为限。AWS 的后续周报特别提醒：同步调用方仍有自己的超时，客户端读取和连接设置也需要配合；网络中的空闲连接限制同样不会随函数时限自动延长。[11 月 24 日官方周报与使用注意事项](https://aws.amazon.com/blogs/aws/aws-weekly-roundup-local-zone-in-bogota-30-minute-lambda-timeout-and-more-november-24-2026/)

**为什么值得关注：** 串联模型和工具调用、转码或文件处理，有时需要连续执行较长时间。上限放宽减少了部分任务仅因执行时长而被迫拆分的情况，但不会替应用处理超时后的状态、重试或重复写入。

**Codex 观察：** 评估长任务时，可以沿着“客户端 → 网关或调用服务 → 函数 → 下游服务”核对时限。函数还在运行而客户端已经放弃，可能导致重试与原任务重叠。是否改成异步任务、保存进度或提供取消能力，仍应由交互需求与失败恢复方式决定，不必因为上限提高就让用户等待半小时。

## 03 · DragonCam：从飞行全景到采样点细节，给土卫六研究补齐画面

**2026-11-24 公告 · 科学探索 / 航天硬件 · 七台科学相机于 11 月中旬前完成集成，任务尚未发射**

NASA 报告，Dragonfly 的 DragonCam 七台科学相机已装入隔热外壳、经过测试并集成到旋翼着陆器。它们用于飞行和地面上的多尺度科学成像；另有两台导航相机在今年夏季安装，因此不能把七台科学相机理解为整机全部相机。[NASA 原始公告](https://science.nasa.gov/missions/dragonfly/nasas-titan-bound-dragonfly-rotorcraft-gets-its-eyes/)

前向和侧向相机提供地形与全景视图，下视相机帮助判断采样设备的部署位置，显微成像仪观察钻取点附近的细节。其他仪器仍将在未来数月交付、集成与测试；公告给出的计划是 2028 年 7 月发射、2034 年末抵达土卫六。

**为什么值得关注：** 一份样本的意义依赖它来自哪里、周围有什么。全景帮助定位地形，近距离图像帮助理解采样点，两者共同为后续成分分析提供背景。仪器之间的配合，让单个测量能够进入更完整的地质解释。

**Codex 建议：** 可以先看公告中的洁净室全景和相机分布动画，了解不同视角承担的任务。这次明确进展是科学相机完成集成，并已有地面图像；它不同于整机验证完成，更不代表已取得土卫六观测数据。此前的飞行模拟与此次硬件集成，是任务准备中的不同环节。
