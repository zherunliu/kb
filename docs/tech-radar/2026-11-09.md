## 01 · Open WebUI：从聊天窗口连接到自己的电脑

**2026-11-08 · AI / 开源 / 开发工具 · v0.13.1 与 v0.13.2 已发布，均非预发布版本**

Open WebUI 在 v0.13.1 中引入 Tether 桌面伴侣，支持 macOS、Windows 和 Linux。设备通过主动向外建立连接接入，不需要开放入站端口；连接后，用户可以从浏览器选择这台设备，让模型、Agent 和自动化任务使用其真实文件、仓库与工具。版本也把 Open Terminal 提供的 Claude Code、Codex、Pi 等 Agent 接入模型选择器，并把操作审批放进聊天界面。[v0.13.1 发布说明](https://github.com/open-webui/open-webui/releases/tag/v0.13.1)

同日发布的 v0.13.2 修复了通过局域网或 Docker 地址、以普通 HTTP 访问时，聊天可能因 `crypto.randomUUID is not a function` 卡住的问题。这个补丁关系到自托管用户的基础可用性。[v0.13.2 发布说明](https://github.com/open-webui/open-webui/releases/tag/v0.13.2)

**为什么值得关注：** 网页聊天与本地开发环境之间少了一次手工搬运文件的过程。手机也能成为入口，但任务实际使用哪台机器、哪个目录和哪些工具，仍由设备连接与配置决定；界面可访问并不意味着计算资源也搬到了云端。

**Codex 建议：** 先读 Tether 和升级说明。v0.13.1 包含数据库结构变更，官方要求多实例同时更新，不支持滚动升级，并建议先备份。新增的 Auto 工具审批默认关闭；它依赖模型判断，不能把“自动批准”理解为安全证明。评估时，设备接入范围和审批方式比聊天入口是否方便更值得先确认。

## 02 · 近期补读：Cursor 把生成应用接到发布流程

**2026-11-05 · AI / 开发平台 · 已向启用 Cloud Agents 的付费计划提供**

Cursor 发布 Live Apps：向云端 Agent 明确提出构建应用后，平台可生成 Web 应用、按需配置 Postgres 数据库、Cursor 登录认证和托管环境，再发布到选定的地址。当前支持 Cursor Origin 和 GitHub 仓库，GitLab 仍在计划中。[原始更新日志](https://cursor.com/changelog/build-live-apps)

发布流程会运行规则检查和 Agent 安全检查，并要求用户明确执行发布。团队可以按人或群组分享，管理员能查看应用、管理发布；个人计划也支持公开分享。这里的安全检查是平台提供的能力，本文没有验证其检出率或漏报情况。

**为什么值得关注：** 一个内部小工具的交付通常还包括数据库、身份认证、运行环境和访问入口。把这些环节接到代码生成之后，能减少原型停留在本机的情况，也让产品设计开始覆盖“谁能使用最终结果”。

**Codex 观察：** 可以重点看发布与分享的交互：生成预览、明确发布、授予访问权限，是不同的动作。评估类似平台时，除了生成效果，还值得了解应用归谁维护、数据如何导出，以及离开托管平台后能保留哪些能力。这些是后续选型问题，不能仅从本次公告推定答案。

## 03 · PROMISE：把火星车工程积累带到月球南极

**2026-11-07 · 硬件 / 科学探索 · NASA 宣布推进研发，目标 2028 年末发射，尚未发射**

NASA 宣布推进 PROMISE 月球车研发，计划在月球南极研究地表、地下物质和资源分布，主任务规划为 18 个月。JPL 将组合 Curiosity 和 Perseverance 火星车的备份飞行部件与工程试验模型，构建这辆六轮车；本次进展包括研发推进与运输合同，并非月面验证完成。[NASA 11 月 7 日公告](https://www.nasa.gov/news-release/nasa-awards-moon-base-transportation-technology-science-projects/)

任务设计采用多任务放射性同位素热电发生器（MMRTG）供电，以支持漫长月夜及永久阴影区的活动。载荷计划包含可取到地下约一米月壤的钻具、光谱仪及温度和辐射传感器；还将演示耐辐射计算系统和自主导航技术。这些目前都是待实施、待验证的任务能力。[任务与载荷介绍](https://www.nasa.gov/mission/promise/)

**为什么值得关注：** 复用不仅是沿用零件，还包括既有软件、测试设施和运行经验。NASA 认为这样能降低成本、缩短集成测试时间；实际节省多少、在新环境中能达到什么表现，仍需后续工程与任务结果支持。

**Codex 观察：** 这条消息适合从“哪些可以复用、哪些必须重新验证”来读。火星任务积累提供了起点，月球南极的温度、照明与地形又提出不同约束。官方称已评估硬件的月球环境兼容性，但这与整车完成测试、成功发射和月面运行仍是不同里程碑。
