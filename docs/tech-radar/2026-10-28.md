## 01 · LFM3：把小模型做成可定制的本地工具

**2026-10-27 · AI / 端侧计算 · 权重已开放，采用 LFM Open License v1.0**

Liquid AI 发布 LFM3 家族，从共享骨干扩展出文本、视觉、音频、全模态和决策模型，首批集中在约 2B 参数规模。新架构混合短卷积、滑动窗口注意力与全局注意力，目标是在端侧资源限制下兼顾长上下文和工具使用。[原始发布公告](https://www.liquid.ai/blog/lfm3)

其中，文本模型 LFM3-1.7B 约有 17.3 亿参数，支持输入与输出合计 256K token 的上下文，面向本地 Agent、结构化输出和领域微调。官方提供 GGUF、MLX 等不同运行格式，并称 4-bit 版本约占 1 GB；实际应用还需要为上下文缓存和运行框架预留内存，不能将这个数字理解为整套应用的固定内存上限。[官方模型卡与运行说明](https://huggingface.co/LiquidAI/LFM3-1.7B)

**为什么值得关注：** 对固定格式提取、有限工具调用等任务，小模型提供了把推理放到设备附近的选择。能否采用，取决于目标任务的成功率、延迟和资源消耗，而不只是通用榜单的名次。开放权重也让专门化训练和部署方式有更多选择。

**Codex 建议：** 先读模型卡的适用范围。团队明确不推荐将该文本模型用于复杂多步推理或 Agent 编程任务；知识密集任务建议结合检索。官方性能数据可作为候选筛选依据，具体应用仍需验证。权重可下载也不等于可以忽略其许可条件。

## 02 · Firefox 159：滚动动画和组件隔离进入正式版

**2026-10-27 · 开发工具 / Web 平台 · Firefox 159 正式发布**

Firefox 159 支持滚动驱动动画：动画进度可以跟随容器滚动位置，或元素进入视口的过程，涉及 `animation-timeline`、`scroll-timeline`、`view-timeline` 等 CSS 能力。阅读进度条、滚动过程中的视觉过渡，由此多了一种由浏览器直接管理进度的实现方式。[正式版发布说明](https://www.firefox.com/en-US/firefox/159.0/releasenotes/)

另一个变化是支持局部自定义元素注册表（scoped custom element registries）。组件可以使用独立于全局 `window.customElements` 的注册表，让不同作用域内同名的自定义元素共存。MDN 同时确认，滚动驱动动画在这一版默认启用。[开发者更新文档](https://developer.mozilla.org/en-US/docs/Mozilla/Firefox/Releases/159)

**为什么值得关注：** 前者可减少为了同步滚动与动画而编写的脚本；后者有助于处理多套 Web Components 集成时的标签名冲突。例如，两个独立组件库都定义了同名按钮，局部注册表为它们提供各自的定义范围。它解决的是组件命名和作用域问题，不代表自动获得安全隔离。

**Codex 建议：** 做界面交互可以先看滚动动画示例；维护组件平台则值得关注局部注册表。Firefox 新增支持不代表所有目标浏览器已经一致，落地时仍应核对兼容性，并为不支持的环境和减少动态效果的用户保留合适表现。

## 03 · Genie 4：一边生成世界，一边接收新的指令

**2026-10-27 · AI / 世界模型 · 受邀测试者研究预览，公众可加入候补名单**

Google DeepMind 公布 Genie 4，展示在交互过程中用自然语言改变天气、加入人物或物体，并继续探索生成环境的能力。模型还可同步生成环境声音与对话。官方称其结合 Gemini 系列能力，帮助维持场景外观、行为与连续性；这些效果来自团队发布的演示。[原始公告与演示](https://deepmind.google/blog/genie-4-a-new-generation-of-world-simulation/)

当前已开始向受邀测试者提供研究预览。后续面向 Project Genie 的 Google AI Ultra 用户，以及 Gemini API、Google AI Studio 早期合作伙伴的开放仍属计划，不能理解为所有订阅者已经能用。[模型页面与开放状态](https://deepmind.google/models/genie/)

**为什么值得关注：** 这类系统让生成内容可以响应后续操作，扩大了交互原型和训练环境的想象空间。对于 Agent 或机器人研究，价值最终要体现在环境是否稳定、动作后果是否可信，以及模拟中学到的行为能否迁移到真实任务。

**Codex 观察：** 官方列出的限制很关键：持续交互目前是几分钟量级，长时间运行或多次复杂修改后，物体和视觉细节可能漂移，多角色互动、真实地点还原和音频准确性仍待改进。观看演示时，可以关注同一物体经过移动、遮挡和修改后是否保持一致；画面逼真本身不能证明物理模拟准确。
