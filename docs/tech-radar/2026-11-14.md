## 01 · Kitesurf：可以自己运行的 Agent 浏览器引擎

**2026-11-13 · AI / 开源 / 开发工具 · 源码已开放，仍处于快速开发的实验性阶段**

Cloudflare 将 Kitesurf 以 Apache 2.0 许可开源，允许开发者阅读、修改、本地运行并部署到自己的 Workers 账户。它在 Workers 上解析 HTML、处理 CSS、执行页面 JavaScript 和渲染截图，并通过 Chrome DevTools Protocol（CDP）连接 Puppeteer 等客户端。此次新增的是源码开放；产品此前已于 8 月介绍。[原始开源公告](https://blog.cloudflare.com/kitesurf-open-source/)

实现分为三部分：Engine 管理会话与客户端连接，PageScript 执行页面，PageRenderer 绘制结果。自建云端实例需要 Workers Paid 计划，因为页面隔离使用 Dynamic Workers；第三方依赖仍保留各自许可。公告明确表示团队还在改进兼容性、可靠性与效率。

**为什么值得关注：** Agent 需要的浏览器能力可以拆成加载内容、执行脚本、读取状态和执行动作。开放实现让开发者有机会检查这些职责如何协作，也能针对特定任务调整环境，而不只是调用一个托管黑盒。

**Codex 建议：** 先看架构和构建要求，再评估具体页面。支持 CDP 说明接入方式较熟悉，不等于所有网站行为都与 Chromium 一致；“更省资源”也仍需用相同任务和环境比较。若想了解浏览器内部如何工作，三个组件的职责划分比先追性能数字更容易形成整体认识。

## 02 · AI Scan：用接口管理“是否允许扫描”

**2026-11-13 · AI / 安全 / 开发平台 · 管理接口更新处于公开预览**

GitHub 为 AI Scan 的组织级、仓库级 REST 端点加入 `repository_scan` 设置，可用 `GET` 查询、用 `PATCH` 启用或停用整仓扫描能力，并与已有的 `pr_scan` 一起更新。组织关闭后，仓库不能自行开启；组织开启后，仓库继承设置，也可以单独退出。企业策略不允许时，启用请求返回 `422`。[GitHub 原始更新日志](https://github.blog/changelog/2026-11-13-manage-ai-scan-for-repositories-using-the-rest-api/)

同时修改两个设置时，只要一项被阻止，两项都不会改变。启用并不会启动扫描：仍由具有写权限的用户按需运行，每次消耗 GitHub Code Security AI credits。功能面向组织拥有的公开仓库，以及具备相应安全产品的私有或内部仓库；不支持 GitHub Enterprise Server。

**为什么值得关注：** 团队管理大量仓库时，安全能力需要有统一配置，也需要保留仓库级例外。把这些规则开放为接口，可以让配置核对和批量推广进入可追踪的工程流程。

**Codex 观察：** 阅读时把“允许使用”“已经执行”“发现并修复问题”分开。接口成功只证明配置变更，不证明仓库完成了扫描；批量更新也要处理策略拒绝和原有例外。此次公告没有给出新的检出率证据，因此不宜据此判断 AI 扫描质量提升了多少。

## 03 · Landsat：长期影像让生态变化有了可比较的时间线

**2026-11-13 科学解读 · 遥感 / 科学探索 · 既有研究与历史影像展示，非当天新采集的全球地图**

NASA Earth Observatory 介绍一项利用 1984—2023 年 Landsat 影像分析红树林范围与树冠密度的研究。文章报告，全球红树林在 2010 年前总体减少，此后出现回升；这并不意味着此前损失已全部恢复，也不代表每个地区都有相同趋势。[NASA 原始介绍与影像对照](https://science.nasa.gov/earth/earth-observatory/a-global-rebound-for-mangroves/)

页面展示的缅甸局部影像分别采集于 2010 年 2 月 14 日和 2026 年 2 月 2 日，来自 Landsat 5 与 Landsat 9。它们直观展示一处区域的变化，但不能替代全球研究的统计范围。文章同时区分了向新区域扩张和退化地区恢复等不同过程。

**为什么值得关注：** 单张卫星图像适合观察某一时刻，多年代数据才能帮助识别变化方向。对于数据产品，保留观测时间、采集设备和分析范围，决定了后来者能否正确比较结果，而不仅是看到一幅有说服力的图片。

**Codex 建议：** 可以先看影像滑动对照，再读时间范围与研究说明。面积增加、树冠变密和生态功能恢复是相关但不同的指标；某地前后两张图也不能单独证明全球趋势。这里最值得借鉴的是证据组织方式：让可视化、数据范围和解释各自承担清楚的角色。
