## 01 · proto：在本机为其他平台准备工具锁文件

**2026-11-14 · 开源 / 开发工具 · 0.64.0 已发布，日期按 GitHub Release**

多语言版本管理工具 proto 发布 0.64.0，新增 `proto lock [tool] [spec]`：解析工具版本、下载预构建产物并记录校验和，不必安装工具。通过 `--platform` 可以同时准备其他平台的记录，例如在开发机上为 Linux CI 补齐锁文件，再配合不可变锁文件模式使用。[项目原始发布说明](https://github.com/moonrepo/proto/releases/tag/v0.64.0)

这条路径不覆盖所有安装方式：原生安装或源码构建的工具仍需实际安装才能验证，因此会被跳过。同一平台的不同构建变体也开始分别记录，避免普通构建与面向不同 CPU 能力的构建混用校验值。

**为什么值得关注：** 团队里“工具版本相同”不一定意味着下载了同一份二进制。操作系统、CPU 架构和构建变体都会影响实际产物。让锁文件明确记录这些差异，可以把环境准备从某台开发机的隐含状态，变成可审查的项目输入。

**Codex 建议：** 先看 `proto lock` 的覆盖范围与跳过条件。它能提前准备下载校验依据，但没有在目标机器运行工具；跨平台锁定成功与项目在该平台构建成功仍需分别确认。如果环境问题来自系统库或编译选项，仅固定版本号和校验和也不足以解决。

## 02 · Secrets Manager：各账户保留自己的密钥资源，统一同步值

**2026-11-13 · 基础设施 / 安全 · 已发布，可在支持 Secrets Manager 的 AWS 区域使用**

AWS Secrets Manager 增加跨账户复制：主账户管理和轮换 secret，另一个账户保留独立副本；副本使用自己账户的客户管理 KMS 密钥加密。主 secret 的值更新时，服务自动传播变化，必要时也可将副本转为独立 secret。[AWS 发布公告](https://aws.amazon.com/about-aws/whats-new/2026/11/secrets-manager-cross-account/)

用户指南明确了几个边界：主、副 secret 必须在同一区域，一个主 secret 最多关联一个跨账户副本；双方账户都要参与配置。复制是异步、最终一致的，可通过状态区分等待、复制中、同步完成和失败。资源策略、KMS 密钥与标签不随值复制，由各账户管理。[复制流程、状态与限制](https://docs.aws.amazon.com/secretsmanager/latest/userguide/cross-account-replicate-secrets.html)

**为什么值得关注：** 多账户架构既需要集中轮换凭据，也希望使用方保留自己的资源权限和加密边界。托管复制把“更新同一份凭据值”和“分别管理各账户资源”结合起来，减少团队自行维护同步脚本的环节。

**Codex 观察：** 配置关联成功不等于新值已经到达副本，轮换后的应用行为还要结合复制状态判断。另一个容易混淆的点是：持续同步的副本会跟随主值变化，不能直接当作保留旧值的不可变备份。真正的恢复方案仍要说明何时断开复制、使用哪一版值，以及应用如何切换。

## 03 · 补读 AlphaGenome 2：同一段 DNA，要结合细胞环境来预测

**2026-11-11 · AI / 科学探索 · 非商业研究 API 已开放，商业研究为私有预览**

Google DeepMind 公布 AlphaGenome 2。模型把 DNA 序列与指定的组织、细胞类型或细胞状态共同作为输入，预测变异对基因表达等分子活动的影响；相比广泛组织的平均信号，它尝试捕捉只在特定细胞环境中出现的差异。研究者也可用自己的单细胞实验数据描述目标状态。[DeepMind 原始研究公告](https://deepmind.google/blog/alphagenome-2-deciphering-how-cells-read-dna-to-better-understand-disease/)

公告提供非商业研究 API 和教程，商业研究需进入私有预览；面向 Antigravity 的配套 Skills 仍属后续计划。团队报告了细胞类型预测和变异识别上的提升，但本期未独立复现。官方明确限定研究用途，尚未获得临床或诊断用途的验证与批准。

**为什么值得关注：** 模型输入不再只有一段序列，还包括“这段序列处于什么细胞环境”。这种条件化建模让研究者能提出更具体的问题：同一个变异，在不同细胞状态下是否产生不同影响，从而缩小后续实验需要排查的范围。

**Codex 建议：** 可以先看公告中两代模型的输入与输出示意图，不必先追性能排名。预测未测量的实验读数，有助于选择下一步实验，却不会自动把预测变成观测事实；发现候选变异、实验确认作用机制和形成临床用途，也仍是不同阶段。
