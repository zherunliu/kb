## 01 · Docker：更新工具本身，不等于沙箱里的信任库已更新

**2026-10-21 更新指引 · 安全 / 开发环境 · 模板已重建，事件于 10 月 20 日披露**

Docker 针对 eMudhra 中间 CA 私钥泄露事件，重建了内置套件的沙箱模板镜像。公告明确：只升级 `sbx` CLI 不会更新已有沙箱；拉取新镜像也不会改变已经创建的环境。保留旧环境时，需要更新其中的证书包并重启应用，工具自带的信任库可能还要另行处理。[Docker 官方指引](https://docs.docker.com/security/security-announcements/#docker-sandboxes-response-to-emudhra-ca-compromise)

研究者披露，八个中间 CA 的私钥受到影响。浏览器与操作系统平台已采取阻止信任等措施，但部分命令行客户端不消费相同的撤销信息，仍依赖软件更新。披露方没有确认这些客户端是否已遭攻击，不能把潜在冒充风险写成已发生的大规模入侵。[事件原始披露（10 月 20 日）](https://emudhra.we-have-a-problem.com/)

**为什么值得关注：** Agent 的依赖安装、仓库下载和 API 调用，都可能发生在独立沙箱内。宿主系统、基础镜像和应用自带证书并不总是同步更新；同一台机器上的浏览器连接安全，也不能证明沙箱中的客户端已采用相同信任状态。

**Codex 建议：** 使用 Docker Sandboxes 时，先按官方指引确认要更新的是哪一层。若选择重建环境，删除前应保存沙箱内文件和未推送提交；自定义模板还需跟随基础发行版更新并重建。这里关注证书信任更新，不建议用关闭 TLS 验证来消除连接错误。

## 02 · createAI：把模型选择与网关配置集中到一个入口

**2026-10-21 · AI / 开发工具 · 新接口已公布，provider 仍为 Beta**

Cloudflare Agents SDK 新增 `createAI`，同时面向 AI SDK 和 Pi AI，统一接入 Workers AI、AI Gateway 模型目录、动态路由及厂商模型对象。旧的 `workers-ai-provider` 和 `ai-gateway-provider` 已冻结功能并标记弃用；公告没有宣布它们当天停止工作。[更新公告](https://developers.cloudflare.com/changelog/post/2026-10-21-createai/)

新接口可使用 Worker 的 `AI` binding，也可使用账户 ID 与 API token，在 Worker 外调用网关。调用方可以配置回退模型、缓存和重试等选项。官方文档提醒，模型 provider 处于 Beta，API 可能在次版本中变化；AI Search 则使用独立的 `ai-search-provider`。[模型接口与状态说明](https://developers.cloudflare.com/agents/models/)

**为什么值得关注：** 多模型应用通常既要选择模型，又要管理鉴权、路由和失败处理。把接入方式集中起来，有助于减少应用中的重复适配代码，也更容易看清某次请求实际经过哪个网关、使用哪组配置。

**Codex 观察：** 值得先看公告的迁移对照表，再检查自己使用的调用路径。接口统一并不意味着不同模型的能力、参数与结果完全相同；回退模型也需要满足原任务的输入和工具调用要求。新接口适合评估接入成本，Beta 状态则意味着升级时仍要核对兼容性。

## 03 · 研究补读：AI 超声评估怎样验证跨场景泛化

**2026-10-21 研究解读 · AI / 科学应用 · 论文发表于 7 月 9 日，并非当天的新产品发布**

Google Research 介绍一项 AI 辅助超声研究：经过简短训练的非超声专科操作人员，按标准路径采集“盲扫”图像，再由移动端模型估计孕周。此次解读重点是更换设备和临床环境后，模型是否仍能保持表现。[团队最新解读](https://www.research.google/blog/empowering-frontline-maternal-care-with-ai-assisted-ultrasound/)

原论文发表于 JAMA Network Open。主要评估包含芝加哥和内罗毕的 385 名参与者，孕周范围为 16 至 36 周。模型仅使用芝加哥的小规模数据进行适配，未用内罗毕数据微调；研究报告，模型的平均绝对误差约为 4.2 天，临床标准约为 4.5 天，达到预设的非劣效标准。这是研究团队的前瞻性评估，不是本文独立复现。[论文与研究范围](https://jamanetwork.com/journals/jamanetworkopen/fullarticle/2851451)

**为什么值得关注：** 应用研究需要跨过的障碍不只是测试集分数，还包括设备、操作人员和数据分布变化。将部分机构的数据留在适配过程之外，有助于检验模型能否迁移到新的实际环境。

**Codex 观察：** 可以先读论文的样本范围与评估设计。“孕周估计不劣于对照”是特定任务、特定条件下的结果，不能扩大成完整产检能力或临床结局已经改善。团队也把低质量输入识别和不确定性提示列为部署中需要考虑的问题。

## 今天值得继续看什么

使用隔离开发环境，优先读 **Docker 的更新范围说明**。接入多家模型，可以看 **createAI 的迁移表和 Beta 提示**。想了解 AI 如何接受真实场景检验，则读 **超声论文的研究设计**，关注适配数据、外部评估与结论范围如何对应。
