## 01 · Kimi K3.1 Pro：服务已上线，完整权重仍需等待

**2026-10-23 Kimi Code 上线；10 月 24 日技术博客 · AI / 开发工具 · 托管可用，权重发布仍为计划**

Kimi 发布 K3.1 Pro 与 Highspeed 版本，提供最高 100 万 token 上下文，覆盖 Kimi、Kimi Work、Kimi Code 和 API。技术博客把它描述为在 K3 基础上扩大后训练投入的模型，并明确完整权重将于 11 月 4 日前发布；因此当前可以调用托管服务，不能据此写成已经可下载完整权重。[技术博客与可用状态](https://www.kimi.com/en/blog/kimi-k3-1-pro) · [博客目录日期](https://www.kimi.com/blog/)

Kimi Code 更新记录标注 10 月 23 日全量上线。该渠道的上下文上限与会员档位有关，Highspeed 也有单独的访问条件；新模型仅支持思考模式，关闭思考会返回错误。官方建议从新会话开始使用，避免沿用旧模型会话造成行为变化和缓存命中下降。[Kimi Code 发布记录](https://www.kimi.com/code/docs/en/kimi-code/whats-new.html)

**为什么值得关注：** 新模型同时进入编码工具和通用工作入口，让长任务能力有更多实际接入场景。技术博客还给出了评测配置与工具环境，便于读者判断一个成绩究竟对应怎样的运行条件。

**Codex 观察：** 可以先读可用状态和评测脚注。官方所称 Highspeed 约 2–3 倍速度，以及编码、三维创作等表现，都不是本文实测；评估时仍需结合任务完成质量、等待时间和使用成本。计划开放权重与今天可自行部署，是两个不同阶段。

## 02 · Agent Skills：可复用工作流标准转入基金会治理

**2026-10-22 · 开源 / Agent 工具 · 捐赠已宣布，版本化与提案机制仍为后续路线图**

Anthropic 宣布把 Agent Skills 捐赠给 Linux Foundation 旗下的 Agentic AI Foundation（AAIF），包括名称、标识、GitHub 组织和域名。使用和贡献标准不要求加入基金会。公告提出后续推进版本化发布、正式提案流程和技能安全指引，但没有把这些规划描述为已全部完成。[Anthropic 捐赠公告](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation)

AAIF 同日确认接纳 Agent Skills、Open Responses、OpenEnv 和 OpenSandbox 四个项目，分别涉及技能封装、模型接口、训练环境和执行沙箱。Agent Skills 用包含指令、脚本和参考资料的目录封装任务知识，供兼容工具按需加载；此次变化主要在治理归属，并非技能格式当天才首次出现。[基金会原始公告](https://aaif.io/news/agentic-ai-foundation-announces-four-new-projects)

**为什么值得关注：** 当团队开始把工作流程写成可复用技能，格式的演进方式也会影响维护成本。公开的提案与版本机制，有助于让不同工具和技能作者围绕同一份规范协调变化。

**Codex 建议：** 值得跟踪的是后续发布怎样说明兼容性和变更范围。共享格式便于搬运指令与资源，但不同宿主的工具、权限和运行环境仍有差异；进入基金会也不等于每个第三方技能都经过安全审查。

## 03 · Dragonfly：让自主降落流程在真实时序下连起来

**2026-10-23 公布 · 航天 / 自主系统 · 地面测试台模拟，尚非实际飞行**

NASA 的 Dragonfly 团队在约翰斯·霍普金斯大学应用物理实验室完成一次综合飞行序列模拟：飞行软件和类飞行航电接收模拟的相机、惯性测量与激光雷达数据，执行寻找安全地点、转向和降落等动作。测试发生在地面计算机测试台，没有在土卫六或空中完成这次飞行。[NASA 测试说明](https://science.nasa.gov/blogs/dragonfly/2026/10/23/nasas-dragonfly-completes-first-simulated-flight/)

相机模拟器用 GPU 实时生成场景，配合接近实际曝光时长的输入，让团队观察不同进程之间的时序交互。后续还计划在实际飞行系统上运行相同序列，并加入故障测试；任务目标是不早于 2028 年发射、2034 年抵达土卫六。

**为什么值得关注：** 自主系统需要把感知、决策和执行连成完整流程。模块单独正确之后，数据能否按时抵达、各部分如何协同，仍需要集成测试回答。

**Codex 观察：** 原文值得看的是逐步增加传感器和动作的测试路径。这次结果支持地面条件下的集成进展，实际飞行系统测试、故障恢复和最终任务表现仍有各自的验证环节。
