# MySQL

## cli

```bash
mysql -h <host> -P <port> -u <username> -p
```

## MySQL 执行流程

MySQL 的框架分为两层：

- server 层：负责建立连接、解析和执行 SQL，主要包括连接器、查询缓存、解析器、优化器和执行器等组件
- 存储引擎层：负责数据的存储和检索，不同的存储引擎提供不同的功能和特性，支持 InnoDB（MySQL 5.5+ 默认存储引擎）、MyISAM、Memory 等多种存储引擎

### 连接器

- 基于 TCP 协议传输：三次握手建立连接，四次挥手断开连接
- 身份认证：用户名、密码、主机权限
- 权限读取：从 mysql.user 表读取权限信息，后续操作基于此权限进行
- 维持连接：最大空闲时间（wait_timeout）默认是 8h
- 使用长连接减少建立连接和断开连接的开销，但会导致内存增长
  > - 定时断开连接
  > - 客户端使用 `mysql_reset_connection()` 重置连接状态

### 查询缓存

对于频繁更新的表，查询缓存命中率很低，MySQL 8.0 移除 server 层的查询缓存

> 使用第三方缓存（如 Redis）或存储引擎层的缓存（如 InnoDB Buffer Pool）来提高查询性能

### 解析器

- 词法分析：将 SQL 语句分解成一个个 token
- 语法分析：检查 SQL 语句是否有语法错误，构建抽象语法树

### 执行 SQL

#### 预处理器

- 检查 SQL 语句中的表或字段是否存在
- 将 `SELECT *` 中的 `*` 替换成具体的字段列表

#### 优化器

制定执行计划，包括索引选择、连接顺序、执行策略等，使用 `EXPLAIN <sql>` 查看执行计划

> `system > const > eq_ref > ref > range > index > ALL`

#### 执行器

根据执行计划执行 SQL 语句，调用存储引擎 API，返回结果
